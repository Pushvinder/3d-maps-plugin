# Package Screenshots for pub.dev

Place your screenshot files in this directory to automatically display them in the **Screenshots** tab on [pub.dev](https://pub.dev).

### Expected File Names:
1. `map_3d_demo.png` - Screenshot showing the photorealistic 3D map view of Eiffel Tower.
2. `markers_demo.png` - Screenshot showing custom circular profile markers and the detail overlay card.

### Guidelines:
- Format: PNG or JPG
- File Size: Keep under 2 MB per image.
- Dimensions: Portrait or Landscape phone screenshots (e.g. 1080x2340).
